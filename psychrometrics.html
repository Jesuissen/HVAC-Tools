Assumption: room sensible load sets supply airflow unless airflow is entered. Positive room moisture load means moisture generated in the room; use a negative value for a net humidification requirement. In summer cooling/dehumidification mode, coil leaving air is taken at saturation at the required humidity ratio, followed by reheat. Winter mode reports direct mixed-air-to-supply heating/cooling and does not invent an apparatus dew point.

Cooling-season secondary-return model using dry-air mass and enthalpy balances: outdoor + primary return are treated in the primary stream; the secondary return bypasses the coil and mixes downstream. The calculated coil-leaving state must remain physically valid (RH ≤ 100%). If the chosen primary fraction makes the required coil state impossible, the tool rejects it instead of forcing a result.
Calculation & chart settings
Ambient pressure
Standard-atmosphere pressure is used when the override is blank.
Chart range
The chart is intentionally SI-only and engineering-focused. Decorative display customization from online chart tools is omitted.
Psychrometric chart
Click a valid location on the chart to load that Tdb + humidity ratio into Basic state. Process points are drawn as numbered markers and connected in order.
